四步，在本機開始。

完整 README ↗

先安裝 Python 3.12 以上、uv 與 Ollama，再將專案下載到自己的電腦。以下指令請在終端機執行。

01

下載專案，進入專案目錄

若已安裝 Git，可複製以下兩行指令：

git clone https://github.com/Ycc1519/ai-news-summarizer.git
cd ai-news-summarizer

沒有 Git 也可以：到 GitHub Repository 選擇 Code → Download ZIP，或直接下載 ZIP 檔案包。解壓縮後，在終端機進入 ai-news-summarizer-main 資料夾，再繼續下一步。兩種下載方式擇一即可。

02

同步環境，下載模型

請確認目前位於含有 pyproject.toml 的專案目錄。首次下載模型需要網路及磁碟空間。

uv sync
ollama pull qwen2.5:3b
03

啟動 Ollama 與摘要工具

開啟 Ollama 應用程式，或在另一個終端機執行 ollama serve，再啟動工具。

uv run ai-news-summarizer
04

貼上新聞，以 /end 結束

可貼上多行文字。輸入單獨一行 /end 並按 Enter，等待摘要完成。

在這裡貼上你的新聞內容……
/end
遇到問題？ 無法連線時，請確認 Ollama 已啟動；找不到模型時，執行 ollama list 確認，並依提示下載模型。也可用 --model 指定其他已下載的本機模型。

開發過程與驗證 / AI COLLABORATION

AI 使用說明

本專案由開發者提出需求、指定技術及回報問題，並由 Codex 協助實作與驗證。以下說明 AI 參與的範圍與實際修正紀錄。

01

用了什麼工具、用在哪裡？

Codex 協助撰寫 Python 摘要工具、錯誤處理、mock 測試、GitHub Actions、README 與這個靜態網站，也協助查找並修正執行問題。Ollama 負責在本機執行 Qwen2.5，實際新聞摘要預設由 qwen2.5:3b 產生。

02

開發者參與及修正了什麼？

開發者指定本機模型與簡單的命令列操作，回報 Actions 失敗，並要求實際執行、修復及檢查金鑰管理。Codex 依此修正 Action 版本、本機套件匯入問題，並加入環境檔忽略規則。

實測曾出現把「下月」改成「三月」及格式不符的回覆，因此加入 JSON 格式約束、降低隨機性、強化日期與數字提示，並在格式錯誤時最多重試一次。

03

如何驗證、還有哪些限制？

Codex 依開發者要求執行 13 個 mock 測試，全部通過；也用本機 Qwen2.5 實際產生摘要，修正後的該次輸出保留了「下月」與「兩間分館」。GitHub 測試、Pages 自動部署及公開網址也已查核成功。這些檢查由 Codex 執行，不代表開發者已逐項親自操作。

本頁的虛構新聞與靜態摘要由 Codex 協助撰寫，並非保存的真實模型輸出。格式通過仍不保證事實正確，使用者需對照原文確認日期、數字與推論。
